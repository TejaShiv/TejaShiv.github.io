Patent Search Engine
Hybrid search over 640 vehicle patents combining BM25 keyword scoring, semantic embeddings, metadata filters, and two-phase cross-encoder re-ranking. Benchmarked end to end and found that retrieval pool size, not re-ranking depth, is the real latency lever.
Python · sentence-transformers · cross-encoder re-ranking

Agentic Test-Repair System
An autonomous agent that detects failing tests, localizes the fault, generates a candidate patch, writes it to disk, and reruns the suite to verify the repair, with bounded retries and validation gates. Evaluated on the QuixBugs benchmark, where near-perfect pass rates exposed training-data contamination and pushed evaluation to a harder held-out suite.
Python · Gemini API · pytest

REST Country Data Platform
Full-stack platform with a React frontend and a Go REST API, deployed through a GitHub Actions CI/CD pipeline to AWS App Runner with zero-downtime releases, Redis caching, and Prometheus/Grafana monitoring.
React · TypeScript · Go · Docker · AWS

Solar Mapper
Django app that maps US commercial sites on an interactive map and estimates solar potential through the NREL PVWatts and Solar Resource APIs, built around a re-runnable pipeline with explicit failure states so bad data surfaces instead of disappearing.
Python · Django · Leaflet · NREL APIs

VIAIT Network Anomaly Detection
ML anomaly detection over 16 million network traffic records at 95%+ accuracy. Profiled the pipeline with cProfile, found the bottleneck was file I/O rather than the model, and cut a 30 minute run to under 2 minutes with chunked reading.
Python · Pandas · scikit-learn · CSE-CIC-IDS2018
